# Downloads

Everything you need to upload to a store, one folder per product.

Each product folder has:
- **1-packages**: the zip to upload. The file name says which store it's for (FOR-CHROME, FOR-EDGE, FOR-FIREFOX).
- **2-store-images**: icon, logo, screenshots and promo tiles, named with their exact sizes.
- **3-listing-text**: the full listing and privacy answers, a short description (under 1,000 characters, for Edge), and search terms.

To download a single file on GitHub: click it, then click the download button (↓) at the top right.
To download everything: on the repository's main page, click **Code → Download ZIP**.

Claude keeps this folder up to date whenever a product changes.
