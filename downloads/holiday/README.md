# Holiday printables: Etsy upload kits

One folder per product (shop: Pantry Printable Co.). Each has:
- **1-files**: the files buyers download (upload these as the listing's digital files; max 5, each under 20 MB).
- **2-listing-images**: 5 listing photos, 3000x2250. Upload in number order (01 = thumbnail).
- **3-listing.md**: title, price, tags, category, description: copy into the Etsy form.
- **4-pins**: 2 Pinterest pins, 1000x1500, with suggested titles in 3-listing.md.

Sources live in `printables/<slug>/`.
